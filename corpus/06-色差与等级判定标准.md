# 色差与等级判定标准（含缸差 / 窑批差处理规则）

本标准规定集团两大事业部产品的色差测量方法、等级判定阈值，以及跨缸、跨窑批发货的处理规则。印染事业部与建陶卫浴事业部的判定阈值不同，使用时须先确认产品所属事业部。

## 1. 适用范围与术语

### 1.1 适用范围

本标准适用于印染事业部（BU-A）的坯布、印花布产品，以及建陶卫浴事业部（BU-B）的岩板、瓷砖产品。本标准不适用于卫浴陶瓷洁具（如坐便器、面盆），洁具的色差判定执行《卫浴洁具外观质量标准》QC-STD-009。

### 1.2 色差测量的基准

色差值 ΔE 是产品实测色与**标准样**之间的 CIELAB 色差，采用 D65 光源、10° 观察角、SCI 模式测量。

标准样的定义在两个事业部有区别：

- **印染事业部**：标准样为客户确认的**大样**，每个「产品 + 色号」组合对应唯一大样，由技术部封样保存，有效期 12 个月。
- **建陶卫浴事业部**：标准样为该产品色号的**首批合格窑批留样**，由质量部封样保存，有效期 24 个月。

同一「产品 + 色号」下的所有染缸或窑批，均对同一标准样测量，因此 ΔE 值之间可直接比较。**若标准样已过有效期或遗失，须重新封样并通知已发货客户，此期间该色号不得进行等级判定。**

## 2. 印染事业部（BU-A）的色差判定

### 2.1 等级阈值

印染产品按与大样的 ΔE 值划分三个等级。测量点取布面对角线五点，取算术平均值。

下表列出印染事业部各等级对应的 ΔE 上限与色牢度要求：

| 等级 | ΔE 上限 | 干摩擦色牢度 | 湿摩擦色牢度 | 可否用于外贸订单 |
|---|---|---|---|---|
| 优等品 | ≤ 1.0 | ≥ 4 级 | ≥ 3 级 | 可 |
| 一等品 | ≤ 2.5 | ≥ 3-4 级 | ≥ 3 级 | 可，需客户书面确认 |
| 合格品 | ≤ 4.0 | ≥ 3 级 | ≥ 2-3 级 | 不可 |

ΔE 超过 4.0 或色牢度低于合格品要求的，判为不合格品，不得入库销售。

**例外情形**：深色系产品（明度 L\* < 30，如藏青、墨绿、黑色）的优等品 ΔE 上限放宽至 **1.5**，一等品放宽至 **3.0**。原因是深色系在 CIELAB 空间中的色差感知阈值高于浅色系，沿用浅色系标准会造成过度判废。该放宽**不适用于**客户在订单中明确标注「色差从严」的批次。

### 2.2 缸差与跨缸发货

缸差指同一「产品 + 色号」在不同染缸之间的色差。由于染液配比、温度曲线、织物批次含水率的微小差异，缸差客观存在，无法完全消除。

跨缸发货是否允许，取决于订单行的 `batch_policy` 字段：

- **SAME_BATCH（必须同缸）**：整个订单行必须由同一染缸供货。库存不足时不得跨缸拼单，须转生产排期。
- **CROSS_OK_WITHIN_TOL（可跨缸，有容差）**：允许跨缸，但任意两缸之间的 ΔE 差值须 ≤ 订单行的 `delta_e_tolerance` 值。该值由销售在下单时与客户约定，默认 1.0。
- **ANY（不限）**：允许任意跨缸，仅需各缸单独满足等级阈值。

**跨缸拼单前必须核对缸间 ΔE 差值，而非各缸对大样的 ΔE 绝对值。** 两缸各自 ΔE 为 0.8 和 0.9 均属优等品，但若两者色偏方向相反，缸间实际差值可能达到 1.7，超出默认容差。

## 3. 建陶卫浴事业部（BU-B）的色差判定

### 3.1 等级阈值

建陶产品按与首批留样的 ΔE 值划分三个等级。测量点取板面九宫格九点，取算术平均值。判定同时考核平整度与吸水率。

下表列出建陶卫浴事业部各等级对应的 ΔE 上限与物理指标要求：

| 等级 | ΔE 上限 | 平整度偏差 | 吸水率 | 可否用于工程集采 |
|---|---|---|---|---|
| 优等品 | ≤ 0.8 | ≤ 0.3 mm/m | ≤ 0.5% | 可 |
| 一等品 | ≤ 1.8 | ≤ 0.5 mm/m | ≤ 0.5% | 可 |
| 合格品 | ≤ 3.2 | ≤ 0.8 mm/m | ≤ 1.0% | 不可 |

ΔE 超过 3.2、平整度偏差超过 0.8 mm/m，或吸水率超过 1.0% 的，判为等外品，仅可用于内部损耗核销，不得对外销售。

**例外情形**：仿古面、岩石纹等**刻意做旧或强纹理**的产品系列，其优等品 ΔE 上限放宽至 **1.2**，因该类产品的设计意图即包含色泽不均。金属釉产品因釉面反射特性，测量须改用 SCE 模式，且优等品 ΔE 上限为 **1.5**。上述放宽均须在产品技术规格书中预先注明，未注明的按标准阈值执行。

### 3.2 窑批差与跨批发货

窑批差指同一「产品 + 色号」在不同窑炉批次之间的色差。窑温曲线、窑位差异、原料批次波动均会造成窑批差，其波动幅度通常大于印染的缸差。

建陶产品的跨批规则与印染不同，采用**色号分档**管理：每个窑批在入库时按实测 ΔE 划入色档（A 档 ΔE ≤ 0.8、B 档 0.8 < ΔE ≤ 1.8、C 档 1.8 < ΔE ≤ 3.2）。

**同一订单行原则上必须由同一色档供货**，不同色档不得混发。工程集采订单因用量大、施工面连续，要求更严：**同一施工面必须使用同一窑批**，即使同属 A 档也不得跨批。该要求须在订单行的备注中显式声明，销售下单时应主动询问客户的施工面划分。

零售订单允许同色档内跨窑批，但须在发货单上标注涉及的窑批号，便于客户在铺贴时按批次分区使用。

## 4. 判定结果的记录与追溯

每批次的色差判定结果须记录以下字段并留存至少 5 年：产品编码、色号、批次号或缸号、测量日期、ΔE 实测值、判定等级、测量设备编号、检验员工号。

判定结果录入 WMS 后写入 `inventory_batch` 表的 `delta_e` 与 `grade` 字段。**已判定的批次如需变更等级，须由质量部经理审批，并在系统中保留变更前后的完整记录，原判定记录不得删除或覆盖。**

## 5. 争议处理

客户对判定结果有异议时，应在收货后 7 个自然日内提出，并保留原包装与未使用产品。超过 7 日或产品已施工、已裁剪的，不再受理色差异议。

复检由质量部会同销售部进行，以封存标准样为准重新测量。复检结论为最终结论。若复检确认判定有误，按《退换货处理办法》QC-STD-007 执行。
